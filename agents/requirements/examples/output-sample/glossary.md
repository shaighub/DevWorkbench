# Glossary — Residential Parking Permit Portal

Terms used in the shall statements. Definitions restate the source and point at requirements. They do not add obligations.

| Term | Definition | Source |
| --- | --- | --- |
| Active | The permit status at issuance. A lookup reports Active only under FR-015. | BRD §6.6, BRD §6.11 |
| Approved | The clerk decision that moves a Submitted application to Approved. | BRD §6.6 |
| CityNotify | The city's existing mail relay for the submission, rejection, and issuance emails. It is not stated to carry the one-time sign-in link. | BRD §6.9 |
| CityPay | The city's existing card processor. It hosts the page where the resident enters the card. | BRD §6.6, BRD §6.12 |
| Current fee | The ordinance amount for the application's zone at the moment the resident is sent to pay. | BRD §6.2 |
| Draft | An application the resident is still filling in. It is not on the clerk queue. | BRD §6.6 |
| Eligible-address list | The cleaned list of street addresses Parking Services supplies for a zone. Comparison is exact against that list. Fuzzy matching is out. | BRD §6.3 |
| Jurisdiction | The state or province of a license plate. | BRD §6.1 |
| Not-found | The lookup result when no permit matches the plate and jurisdiction. It is not an Active permit. | BRD §6.11 |
| Parking-clerk role | The session started only when city single sign-on asserts the group parking-clerk. | BRD §6.10 |
| Proof-of-address file | The single file on an application. The sponsor also says proof of address. PDF, JPEG, or PNG, no larger than 10 megabytes. | BRD §6.4 |
| Rejected | The clerk decision on a Submitted application when a reason of at least 15 characters is recorded. | BRD §6.5 |
| Revoked | A permit status a clerk sets from Active with a listed reason code. A lookup does not report it as Active. | BRD §6.8 |
| Submitted | An application accepted onto the clerk review queue, with the submission time in UTC. | BRD §6.6 |
| Suspended | A permit status a clerk sets from Active with a listed reason code. A lookup does not report it as Active. | BRD §6.8 |
| Zone | An ordinance parking area. The current card names R-A Residential Core at 60 US dollars a year and R-B Waterfront at 90 US dollars a year. | BRD §6.2 |
